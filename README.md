# Курсовая работа: Трекер привычек

## Описание проекта

Данный проект представляет собой трекер привычек, который помогает пользователям отслеживать и выполнять свои привычки. Приложение включает три модели: Привычка, Приятная привычка и Пользователь. Когда приходит время выполнения привычки, пользователю отправляется уведомление через Telegram-бота.

## Модели

### 1. Привычка

Модель Привычка представляет собой основную структуру для хранения информации о привычках, которые пользователь хочет развивать. Она включает в себя следующие поля:

- id: Уникальный идентификатор привычки.
- owner: создатель привычки(присваивается при создании).
- place: место выполнения привычки.
- time: время во сколько она будет выполняться.
- action: сама привычка - дествие.
- related_habit: связанная приятная привычка(можно выбрать либо ее, либо придумать себе вознаграждение за выполнение).
- reward: вознаграждение за выполнение.
- execution_time: сколько по времени длится привычка(максимум 2 минуты).
- is_public: признак публичности, чтобы другие пользователи могли видеть и делиться своими привычками.
- days_of_week: дни недели в которые будет выполняться привычка(нельзя не выполнять привычку реже чем 1 раз в неделю).
- 

### 2. Приятная привычка

Модель Приятная привычка расширяет функциональность основной модели привычек, добавляя возможность пользователю отмечать привычки, которые приносят ему радость или удовольствие.
- id: Уникальный идентификатор привычки.
- owner: создатель привычки(присваивается при создании).
- action: сама привычка - дествие.
- is_public: признак публичности, чтобы другие пользователи могли видеть и делиться своими привычками.
- is_nice: признак приятной привычки.

### 3. Пользователь

Модель Пользователь хранит информацию о пользователях приложения. Она включает в себя:

- id: уникальный идентификатор пользователя.
- email: почта пользователя.
- first_name: имя пользователя.
- last_name: фамилия пользователя.
- phone: номер телефона для связи (если требуется).
- tg_chat_id: уникальный идентификатор пользователя в Telegram для отправки уведомлений.
- city: город пользователя.
- avatar: аватар пользователя.
- is_active: признак активности.

## Функциональность

- **Добавление привычек**: Пользователи могут добавлять новые привычки и приятные привычки через API приложения.
- **Уведомления**: Каждый день в установленное время пользователи получают уведомления через Telegram о том, что пора выполнить свою привычку.
- **Документация**: В проекте настроенна документация для фронт-энда через swagger и redoc.

## Установка

Для запуска проекта выполните следующие шаги:

1. Клонируйте репозиторий:
   
git clone https://github.com/VasiliySochnev/course_work_5/tree/feature_1


2. Установите зависимости:
   
poetry install

3. Настройте Telegram-бота, получив токен и добавив его в настройки приложения.


4. Запустите приложение:
   
python manage.py runserver

5. Запустите redis для работы задачи для оправления уведомлений

6. Запустите celery и celery-beat

## Запуск приложения через Docker desktop

### Для Windows:
1. Перейдите на [страницу загрузки Docker Desktop для Windows](https://www.docker.com/products/docker-desktop/).
2. Нажмите на кнопку "Download for Windows".
3. Запустите загруженный установочный файл и следуйте инструкциям на экране.
4. После завершения установки, откройте Docker Desktop.

**Примечание:** Для работы Docker Desktop на Windows требуется Windows 10 или более новая версия (Pro или Enterprise). Docker также использует WSL 2, который необходимо установить отдельно, если он еще не настроен.

### Для macOS:
1. Перейдите на [страницу загрузки Docker Desktop для macOS](https://www.docker.com/products/docker-desktop/).
2. Нажмите на кнопку "Download for Mac".
3. Откройте загруженный файл `.dmg` и перетащите Docker в папку "Программы".
4. Запустите Docker Desktop из папки "Программы".

**Примечание:** Для работы Docker на macOS требуется macOS 10.14 или более новая версия.

### Запуск Docker Desktop
После завершения установки запустите Docker Desktop, и он автоматически начнёт настройку контейнерной среды на вашем компьютере.

